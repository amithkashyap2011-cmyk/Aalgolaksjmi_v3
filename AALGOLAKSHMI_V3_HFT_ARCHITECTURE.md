## 3. ⚡ C++ HFT Starter Code (Execution Engine)

**`cpp-hft-engine/src/main.cpp`**
```cpp
#include <iostream>
#include <thread>
#include <zmq.hpp>
#include "LockFreeQueue.h"
#include "ExecutionEngine.h"

// Core HFT configuration: CPU Pinning & Memory Pools
void pinThreadToCore(int core_id) {
    cpu_set_t cpuset;
    CPU_ZERO(&cpuset);
    CPU_SET(core_id, &cpuset);
    pthread_setaffinity_np(pthread_self(), sizeof(cpu_set_t), &cpuset);
}

int main() {
    std::cout << "[HFT] Initializing Ultra-Low Latency Execution Engine v3" << std::endl;
    
    // Lock-free queue for signals generated by Rust
    LockFreeQueue<TradeSignal> signalQueue(1024);
    ExecutionEngine execEngine;

    // ZeroMQ Context for Rust -> C++IPC
    zmq::context_t context(1);
    zmq::socket_t subscriber(context, ZMQ_SUB);
    subscriber.connect("tcp://localhost:5555");
    subscriber.set(zmq::sockopt::subscribe, "");

    std::thread executionThread([&]() {
        pinThreadToCore(1); // Pin to Core 1
        while (true) {
            TradeSignal signal;
            if (signalQueue.pop(signal)) {
                // Pre-trade inline check < 1 microsecond
                if (execEngine.preTradeRiskCheck(signal)) {
                    execEngine.executeOrder(signal);
                }
            }
        }
    });

    std::thread zmqThread([&]() {
        pinThreadToCore(2); // Pin to Core 2
        while (true) {
            zmq::message_t msg;
            auto res = subscriber.recv(msg, zmq::recv_flags::none);
            if (res) {
                // Fast-path parsing
                TradeSignal sig = parseZeroMQPayload(msg);
                signalQueue.push(sig); // Non-blocking push
            }
        }
    });

    executionThread.join();
    zmqThread.join();
    return 0;
}
```

## 4. 🦀 Rust Microservices Starter Code

**`rust-services/src/main.rs`**
```rust
use tokio::sync::mpsc;
use zeromq::{PubSocket, Socket};
use tonic::{transport::Server, Request, Response, Status};

mod strategy;
mod risk;

#[tokio::main(worker_threads = 4)]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    println!("🚀 Starting AALGOLAKSHMI Rust Microservices Layer");

    // ZeroMQ Publisher to C++ HFT Engine
    let mut publisher = zeromq::PubSocket::new();
    publisher.bind("tcp://127.0.0.1:5555").await?;

    // Aaryan Core + Hybrid Evaluation
    let (tx, mut rx) = mpsc::channel(100);

    tokio::spawn(async move {
        while let Some(signal) = rx.recv().await {
            // Evaluated by Lakshmi Engine Capital Check
            let final_action = risk::evaluate_cvar_limits(&signal);
            
            if final_action.is_valid {
                // Publish to C++ execution queue instantly
                let payload = format!("{}|{}|{}", signal.symbol, signal.side, signal.qty);
                publisher.send(payload.into()).await.unwrap();
            }
        }
    });

    // Strategy loop simulator
    strategy::start_engine_loop(tx).await;

    Ok(())
}
```

## 5. 🔗 Inter-Service API Contracts & Comms

We strictly use **ZeroMQ (TCP/IPC) for Backend ↔ Backend** due to its lock-free low latency (Zero-copy operations).
We use **gRPC for Frontend ↔ Backend** streaming.

**`trading.proto`**
```proto
syntax = "proto3";
package hft_gateway;

service HybridEngineService {
    rpc StreamMarketData(SymbolRequest) returns (stream MarketTick);
    rpc SubmitManualOrder(OrderRequest) returns (OrderResponse);
    rpc GetStrategyWeights(Empty) returns (WeightMatrix);
}

message SymbolRequest { string symbol = 1; }
message MarketTick { 
    string symbol = 1; 
    double bid = 2; 
    double ask = 3; 
    int64 timestamp = 4;
}
message OrderRequest {
    string symbol = 1;
    string side = 2;
    double qty = 3;
    bool is_iceberg = 4;
}
```

## 6. 🛡️ Risk & Derivatives Implementation Notes

**Lakshmi Capital Allocation (in Rust)**:
- Subscribes to real-time equity curves.
- Computes **95% VaR (Value at Risk)** using historical Monte Carlo simulations.
- If current market volatility spikes, the Kelly Fraction limits order sizes broadcasted to the C++ Engine from `0.15` to `0.02`.

**Options & Greeks**:
- Built into the `rust-services/src/risk/greeks.rs`.
- Implements Black-Scholes approximations natively tracking Gamma exposure to ensure the combined Portfolio Delta remains `Neutral`.

## 7. ☁️ Enterprise Deployment Steps (Kubernetes)

To achieve zero-downtime ML deployment (Aayush Engine) and HFT stability:

1. **Kernel Bypass Setup (Linux)**
   Ensure the host nodes run with isolated CPUs.
   ```bash
   isolcpus=2,3,4 nohz_full=2,3,4 rcu_nocbs=2,3,4
   ```
2. **Compile HFT Engine (Release mode, -O3)**
   ```bash
   mkdir build && cd build
   cmake -DCMAKE_BUILD_TYPE=Release ..
   make -j8
   ```
3. **Build Rust Services (Release, LTO)**
   ```bash
   cargo build --release --target x86_64-unknown-linux-musl
   ```
4. **Deploy via Helm / Docker-Compose**
   The network must utilize `hostNetwork: true` on Kubernetes to avoid the latency overhead of `iptables` and VXLAN overlays.

## 8. 🏎️ Performance & Latency Optimization Notes

1. **Cache Locality**: The C++ Order Book is structured using contiguous memory arrays (`std::array` instead of pointer-heavy `std::map`) to fit inside L1/L2 CPU caches.
2. **Lock-Free Concurrency**: Used `SPSC` (Single-Producer Single-Consumer) ring buffers (`boost::lockfree` or custom atomic rings) between the ZMQ Receiver thread and the Order Execution thread.
3. **Rust Threading**: Tokio configured strictly for compute-bound async operations pinning futures directly on worker cores.
4. **Zero-Copy Serialization**: Avoiding JSON inside the execution loop entirely. The C++ to Rust payload is packed as a continuous C-struct byte buffer.
