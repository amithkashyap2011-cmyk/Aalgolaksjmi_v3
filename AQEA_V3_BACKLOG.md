# AQEA v3 Research Backlog

This document outlines the strategic priorities for the next research phase (v3.0).

## 1. Regime Accuracy & Transition Detection
- **Regime Lag Reduction:** Improve the speed at which the engine detects market shifts (currently 80.31% accurate but reactive).
- **Predictive Forecasting:** Transition from "Current Regime" to "Next Regime" forecasting (Phases initiated in v2.3A).
- **Hybrid Regime States:** Explore probabilistic regime membership (e.g., 60% Trending, 40% Transition).

## 2. Smart Money Refinement (SMC)
- **Signal Purity:** Increase the purity of liquidity sweep and order block detection.
- **FVG Confluence:** Improve the integration of Fair Value Gaps as magnets for institutional price action.
- **Microstructure Mapping:** Better link SMC footprints to real-time order flow imbalances.

## 3. Execution Quality Improvements
- **PPO Optimization:** Deepen the execution agent's authority over order slicing and limit order placement.
- **Slippage Reduction:** Refine entry/exit timing using high-frequency order book snapshots.

## 4. Signal Integration Architecture
- **Consensus Voting:** Replace "Winner Take All" routing with a stable, noise-calibrated consensus mechanism.
- **Dynamic Confidence Gating:** Calibrate model influence based on real-time drift and regime specialization.
